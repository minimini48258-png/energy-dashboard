# ⚡ 電力需給分析ダッシュボード

公共施設の30分値電力使用量データを可視化・分析するStreamlitアプリです。
地域新電力事業のエネルギー小売検討に活用することを想定しています。

## 機能（MVP）

- **Excelデータ読み込み**：複数ファイル対応、列名の自動マッピング
- **需要カーブ表示**：施設別 / 全施設合計の30分値折れ線グラフ
- **KPI表示**：積算使用量・最大・平均・最小
- **需要パターン分析**：
  - 月別使用量
  - 時間帯別平均使用量
  - 平日・休日比較
  - 施設別年間使用量ランキング
  - 日別使用量
- **供給分析**（需要分析と同じ構成で、読み込んだ供給データ＝発電所の30分値を分析）：
  - 供給カーブ：電源別 / 全電源合計の30分値グラフ。需要データがあれば同期間の需要と重ね合わせ
  - KPI：積算発電量・最大出力（kW）・平均
  - 供給パターン分析：月別発電量、時間帯別平均発電量、季節別の時間帯平均、電源別発電量ランキング、日別発電量
  - 供給グループ管理（「データ読み込み」ページ）：電源ごとに電源種別（住宅太陽光・事業用太陽光・小水力など）と
    地域を設定。電源種別は電源名から自動判定し、表で修正・保存できる。供給分析で電源種別別・地域別の絞り込みと
    グループ合計に使用
- **グループの種別追加**：需要側の機能種別に「住宅」「事業所」を追加（施設名から自動判定）。
  需要の機能種別・供給の電源種別とも、「データ読み込み」ページの「➕ 種別を追加する」から独自の種別を追加できる
- **需給バランス**：太陽光・蓄電池・市場調達との需給比較
- **収支シミュレーション**：小売単価一律での簡易P&L試算
- **小売FS（詳細収支）**：
  - 施設ごとの契約電力・電圧区分・料金プラン（基本料金＋従量料金：一律／時間帯別）
  - 電圧区分別の託送料金、燃料費調整、再エネ賦課金、容量拠出金（簡易試算）
  - JEPX想定単価・予備費率を反映した電力調達費
  - 損益計算書ふうの月別・年間サマリー、JEPX価格の感度分析、CO2排出量・地産電源比率
  - 「電力小売FS 収支試算ツール」の計算ロジック（売上総利益 = 売上高 − 再エネ賦課金 −
    (電力調達費＋託送料金＋容量拠出金)）に準拠した簡易版
- **PPA採算性シミュレーター**：「小売電気＋オンサイトPPA一体単価」事業の採算性検証
  - 顧客条件・太陽光条件・小売電力条件・維持管理・ファイナンス・リスクを設定し、
    顧客メリット／事業者メリット（事業IRR・エクイティIRR・NPV）／金融成立性（DSCR）を試算
  - 損益分岐PPA単価の逆算（NPV=0／事業IRR目標／エクイティIRR目標／最低DSCR目標の4条件）
  - 実需要データ（30分値）と連携し、太陽光でどれだけ需要を賄い・どれだけ余り・どれだけ市場等から
    調達が必要かを実績ベースで算出（日/週/月単位の需給バランス、季節×平日休日の8パターン分析つき）
  - 主要11変数の感度分析、シナリオ保存・比較
  - 計算式・設計方針の詳細は `README_ppa.md` を参照

## 対応データ形式

| 列名 | 内容 |
|------|------|
| `datetime` | 日時（30分刻み）|
| `facility_name` | 施設名 |
| `consumption_kwh` | 使用電力量 (kWh/30min) |

列名が異なる場合は読み込み後に手動マッピングできます。
日本語列名（`日時`、`施設名`、`使用電力量`など）にも対応しています。

## セットアップ

```bash
pip install -r requirements.txt
```

## 起動

```bash
streamlit run app.py
```

## サンプルデータの生成

```bash
python generate_sample.py
```

5施設・1年分（87,600行）のサンプルCSVとExcelが `data/sample/` に生成されます。

## 小売FSタブの注意事項

料金プラン・託送料金・再エネ賦課金・容量拠出金の初期値はいずれも目安値です。
実際の数値は各エリアの料金表・託送供給等約款・OCCTO公表資料等で確認のうえ入力してください。
施設設定・料金プランはセッションを超えて `/tmp/energy_dashboard/` にJSON保存されます
（同一環境での再利用を想定。異なる環境へ複製する場合は該当ファイルをコピーしてください）。

## シナリオ・保存まわりの機能（2026-11 追加）

- **保存先の切り替え**：設定・キャッシュの保存先は既定で `/tmp/energy_dashboard`（Community Cloud等は再起動で消える）。
  永続領域がある環境では環境変数 `ENERGY_DASHBOARD_DATA_DIR` で保存先を指定できる（`storage.py`）
- **シナリオのJSONバックアップ**：「小売FS → シナリオ比較」で全シナリオを書き出し／読み込み。再起動後の復元に使う
- **余剰電力の扱い**：シナリオ設計⑥で「余剰も全量買取＋JEPX売却」と「自家消費できる分だけ調達」を選択
- **JEPX価格の加減額**：シナリオ設計⑤で目安値・実績の両方に一律加減（市況の上振れ・下振れの感度用）
- **集約戸数**：「町内363戸合計」のような集約行は戸数を指定して、段階料金を1契約あたりで計算（施設名から自動判定）
- **契約電力の取り込み**：施設名と契約電力(kW)の一覧（CSV／Excel）から一括反映
- **シナリオ比較の整合**：施設設定にない施設は需給バランスからも除外／JEPX実績を試算結果ページと同じく反映／
  保存済み供給データが消えている場合は現在読み込み中の供給データで代替して警告表示／粗利率・市場売却収入も表示

テスト：`pip install pytest && python -m pytest tests`
