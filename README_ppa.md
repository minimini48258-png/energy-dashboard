# PPA採算性シミュレーター（小売電気＋オンサイトPPA）

地域新電力・小売電気事業者が、住宅または事業所の屋根に太陽光発電設備を自己所有で設置し、
「小売電気料金＋オンサイトPPA」を一体化した単一単価（例：25円/kWh）で顧客に供給するビジネスモデルの
採算性を検証する機能です（energy-dashboardの「💰 PPA採算性」グループ）。

単なる太陽光投資回収計算ではなく、**小売電気＋PPA＋余剰電力価値＋長期設備保有＋ファイナンス**を
統合した事業モデルとして計算します。

> このドキュメントは、本機能と同じ設計で先に作成した独立アプリ
> （GitHub `ppa-retail-simulator`、Next.js/TypeScript版）のREADMEを、
> energy-dashboardへのPython移植に合わせて書き直したものです。計算結果は両者で一致することを確認済みです。

---

## 1. 要件整理

想定ビジネスモデル（前提）：

- 顧客の初期費用は0円。太陽光設備は事業者が自己所有し、契約終了後も原則として顧客へ無償譲渡しない
- 設備の維持管理・パワコン交換・最終的な撤去/更新/残存価値計上は事業者が負担
- 顧客には太陽光由来/系統由来を意識させない「一体単価（円/kWh）」で課金する
- 余剰電力（自家消費されなかった太陽光電力）は事業者が引き取り、他需要家への供給等に利用する
- 事業所については、移転・倒産・建物売却・賃貸借終了等による途中解約リスクも考慮する

検証したいこと：

1. 顧客にとって現在の電気料金よりメリットがあるか
2. PPA・小売事業者にとって採算が成立するか
3. 金融機関から長期融資を受けても成立するか（DSCR等）
4. どの条件が採算性を大きく左右するか（感度分析）
5. 住宅・事業所それぞれでどの程度の料金単価なら成立するか（損益分岐PPA単価）

## 2. 電力・お金の流れ（二重計上防止の設計）

このモデルで最も重要なのは、「一体単価で課金する」ことと「太陽光由来／外部調達由来でコスト構造が
全く異なる」ことを、二重計上や漏れなく両立させることです。以下の**2本の恒等式**を核にしています。

```
恒等式①（電力量）: 太陽光発電量 = 自家消費量 + 余剰電力量
恒等式②（電力量）: 顧客使用量   = 自家消費量 + 外部調達電力量
```

お金の流れは、この電力量の分解に対してのみ以下のように結びつけます。

| 電力の種類 | 顧客への請求 | 事業者側のコスト |
|---|---|---|
| 自家消費分（太陽光） | 一体単価 × 自家消費量（顧客使用量の一部として課金） | **外部調達原価はかけない**（設備は自己所有のため、コストはCapEx償却・O&M・保険等で別途計上済み。ここに調達原価を乗せると二重計上になる） |
| 外部調達分（系統） | 一体単価 × 外部調達量（顧客使用量の一部として課金） | 外部調達原価（系統調達単価＋託送＋容量拠出金＋再エネ賦課金＋その他）× 外部調達量 |
| 余剰分（太陽光） | 顧客請求には含まれない | 余剰売却単価 × 余剰電力量 が事業者の収入（顧客収入とは別建て） |

二重計上・計算漏れを避けるための具体的なルール：

- 顧客収入は **顧客使用量 × 一体単価** の1本だけ。自家消費分・外部調達分を分けて別々に請求しない
- 外部調達原価は **外部調達電力量にのみ** 適用する。自家消費分の太陽光電力には適用しない
- 再エネ賦課金は **外部調達電力量にのみ** 課す、という前提にしている（自家消費分の太陽光は対象外）。
  これは制度上の要確認事項（§8参照）
- 余剰電力の売却収入は、顧客への請求とは完全に別の収入ラインとして計上する

この2本の恒等式は `ppa_retail_calc.compute_energy_flow()` に実装されています。

## 3. 計算モデル・数式（`ppa_retail_calc.py`）

計算は年次（1年〜シミュレーション期間）で行います。

### 3.1 発電量（`compute_annual_generation`）

```
初年度発電量 =
  容量×kWh/kWモード: 太陽光容量(kW) × 年間発電量(kWh/kW/年)
  直接入力モード   : 初年度年間発電量（直接入力値）

t年目発電量 = 初年度発電量 × (1 − 経年劣化率)^(t−1)
```

### 3.2 使用量（`compute_annual_consumption`）

```
t年目使用量 = 初年度使用量 × (1 + 使用量増減率)^(t−1)
```

### 3.3 自家消費・余剰・外部調達（`compute_energy_flow`）

```
自家消費量 = min(発電量 × 自家消費率, 発電量, 使用量)
余剰電力量 = 発電量 − 自家消費量
外部調達電力量 = 使用量 − 自家消費量
```

自家消費率は、蓄電池・エコキュート等を導入している場合、ベース自家消費率にそれぞれの
「自家消費率への上乗せ(pp)」を加算した値（100%でクリップ）を使用します
（`compute_effective_self_consumption_rate_pct`）。蓄電池の充放電シミュレーションそのものは
行わない簡易近似です（§7将来拡張）。

### 3.4 顧客経済性（`compute_customer_economics`）

```
現在の年間電気代 = 使用量 × 現在単価 × (1 + 現在料金上昇率)^(t−1)
新プランの年間電気代 = 使用量 × 一体単価   （契約期間中は固定と仮定）
年間削減額 = 現在の年間電気代 − 新プランの年間電気代
```

### 3.5 外部調達原価（`compute_procurement_unit_cost_series`）

```
外部調達単価(t) = (系統調達単価 + 託送料金等 + 容量拠出金等 + その他小売原価 + 再エネ賦課金)
                   × (1 + 小売原価上昇率)^(t−1)
外部調達費(t) = 外部調達電力量(t) × 外部調達単価(t)
```

### 3.6 収入

```
顧客電気料金収入(t) = 顧客使用量(t) × 一体単価   ※リスク調整前（§3.9参照）
余剰電力売却収入(t) = 余剰電力量(t) × 余剰単価(t)
総収入(t) = 顧客電気料金収入(t) + 余剰電力売却収入(t) + その他収入(t)
```

### 3.7 維持管理費（`compute_opex_series`）

```
O&M費(t)   = 固定額 or 初期設備費 × O&M率
保険料(t)  = 固定額 or 初期設備費 × 保険率
設備管理費(t) = 入力値（年額固定）
修繕費(t)  = 年次スケジュールで指定された金額（該当年のみ）
パワコン交換費(t) = 指定年のみ計上
```

最終年度の扱い（3パターンから選択、本モデルは設備を事業者が長期所有する前提）：

```
撤去       : 最終年度に (撤去費用 + リサイクル費用) を計上
設備更新   : 最終年度に設備更新費用を計上（シミュレーション期間は延長しない簡略化）
残存価値計上: 最終年度に残存価値を収入として計上
```

### 3.8 ファイナンス（`compute_financing_series`）

```
自己資金 = 初期投資 × 自己資本比率
借入金額 = 初期投資 − 自己資金
融資手数料 = 借入金額 × 融資手数料率

据置期間中: 元金返済 = 0、利息 = 借入残高 × 金利
元利均等  : 毎年の元利合計が一定になるよう元金を算出（アニュイティ方式）
元金均等  : 毎年の元金が一定（残存期間で均等按分）、利息は残高に応じて逓減
```

### 3.9 途中解約・倒産・移転リスク（`compute_risk_adjusted_flow`、期待値ベースの簡略モデル）

```
年間ハザード率 h = 年間解約確率 + 年間倒産確率 + 年間移転確率
生存確率 survival(t) = (1 − h)^t
```

途中終了した契約分の扱いは、選択した処理方法（A〜D）に応じて以下のように収入・費用を調整します。

- **B. 余剰電力として売却**: 終了した契約分の自家消費相当電力を、余剰電力として売却したとみなす
- **A. 契約承継**: 承継成功率ぶんは契約が継続するとみなし、失敗分はBと同じ扱い
- **C. 設備撤去**: 終了した契約分の収入・費用を単純にゼロ化（簡略化。撤去費用の期待値計上は未実装）
- **D. 中途解約金**: Bの継続処理に加え、限界解約確率×解約金を収入計上

契約期間（`contract_years`）を超えた年度は、リスク発生の有無によらず「顧客請求終了・自家消費相当分は
余剰電力として売却」という扱いで統一しています（`simulate()`内で分岐）。

> **重要な限界**: このモデルは「1設備＝1契約」のMVPであり、期待値計算は本来ポートフォリオ（多数契約）
> で初めて意味を持つ近似です。単体資産では、ある年に契約が終了する/しないは0か1かの事象であり、
> 期待値（例: 生存確率70%）は実際には起こり得ません。将来のポートフォリオ化（§7）で、多数の需要家を
> 束ねることによりこの近似が実態に近づきます。

### 3.10 キャッシュフロー・評価指標（`simulate()`, `npv()`, `irr()`）

```
EBITDA相当(t) = 総収入(t) − (外部調達費 + O&M + 保険料 + 設備管理費 + 修繕費 + パワコン交換費
                              + 撤去リサイクル費 + 設備更新費)(t)
元利返済前CF(t) = EBITDA相当(t) + 残存価値収入(t)
元利返済後CF(t) = 元利返済前CF(t) − 元利返済額(t)
累積CF(t) = 累積CF(t−1) + 元利返済後CF(t)   ※初期値 = −(自己資金 + 融資手数料)

DSCR(t) = 元利返済前CF(t) ÷ 元利返済額(t)   （返済額0の年は算出対象外）

NPV = Σ CF(t) / (1+割引率)^t   (t=0,1,2,...)
IRR = NPV=0となる割引率（Newton法→二分法フォールバックで数値的に算出）

事業キャッシュフロー   = [−初期投資, 元利返済前CF(1), 元利返済前CF(2), ...]  （無借金換算）
エクイティキャッシュフロー = [−(自己資金+融資手数料), 元利返済後CF(1), 元利返済後CF(2), ...]

事業IRR     = irr(事業キャッシュフロー)
エクイティIRR = irr(エクイティキャッシュフロー)
NPV(事業)    = npv(割引率, 事業キャッシュフロー)
NPV(エクイティ) = npv(割引率, エクイティキャッシュフロー)
単純投資回収年 = 事業キャッシュフローの累積が初めて0以上になる年（端数年を線形補間）
```

> **注記**: 「NPV（事業）・事業IRR」は無借金換算（元利返済前CF基準）のため、定義上、金利の変化は
> これらに影響しません（金利はエクイティIRR・DSCRにのみ影響します）。感度分析でも同様です。

### 3.11 損益分岐PPA単価（`compute_breakeven()`、本機能の中心）

一体単価を上げると、顧客収入（使用量×単価）が全年度で一律に増加し、他の収入・費用は単価に依存しない
ため、NPV・IRR・DSCRは単価に対して単調に改善します。この単調性を利用し、以下4条件それぞれについて
二分法で「条件を満たす最低単価」を逆算します。

```
① NPV(エクイティ) = 0 となる単価
② 事業IRR が目標値（例: 5%）以上になる単価
③ エクイティIRR が目標値（例: 8%）以上になる単価
④ 最低DSCR が目標値（例: 1.2）以上になる単価

事業成立最低単価 = 上記4つの単価のうち最大値（＝すべての条件を同時に満たす最低単価）
```

探索範囲は 0〜200円/kWh。上限でも条件を満たせない場合は「算出不可」と表示します。

### 3.12 感度分析（`compute_sensitivity()`）

11変数（PPA/小売料金・設備費・年間発電量・自家消費率・外部電力調達単価・金利・補助金・契約期間・
O&M費・撤去リサイクル費・解約率）をそれぞれ単独で ±10%／±20% 変化させ、事業IRR・NPV(事業)・最低DSCRを
再計算します。各変数のNPV変化幅（±20%時の最大−最小）でランキングし、影響度の大小を可視化します
（`rank_sensitivity_impact()`）。

## 8. 要確認事項（制度・税務・計算前提）

- **再エネ賦課金の扱い**: 自家消費分の太陽光電力には再エネ賦課金がかからず、外部調達電力のみに
  課されるという前提で計算しています。実際の制度上の扱いは要確認です。
- **税務処理**: 消費税額の計算は行っておらず、「税込」「税抜」の区分を入力者が統一する前提の簡易対応です。
- **容量拠出金等の小売原価**: 円/kWh換算した簡易値を入力する設計にしています。実際の試算には別途
  詳細な制度確認が必要です。
- **託送料金**: 電圧区分・エリアにより大きく異なります。サンプル値は目安であり、実際の料金表の確認が必要です。
- **撤去費用の期待値計上（途中解約時）**: §3.9の「C. 設備撤去」処理では、途中解約時に発生する
  撤去費用の期待値計上を省略しています。
- **設備更新時のシミュレーション期間**: terminal_treatment=replacement を選んだ場合、最終年度に
  更新費用を計上するのみで、期間延長はしていません。
- **元利均等返済の端数処理**: 浮動小数点演算による丸め誤差が生じる可能性があります。

## 9. サンプル値

【住宅】太陽光6kW・年間発電量1,100kWh/kW・年間使用量6,000kWh・自家消費率50%・現在28円/kWh・
新プラン25円/kWh・設備費25万円/kW・契約期間20年・自己資本比率40%（単体資産のため高め、仮定値）

【事業所】太陽光50kW・年間発電量1,100kWh/kW・年間使用量100,000kWh・自家消費率80%・現在26円/kWh・
新プラン24円/kWh・設備費18万円/kW・契約期間20年・自己資本比率20%（規模の経済を見込み低め、仮定値）

その他の原価・金利・維持管理費等は「仮定値」であることを明示した上で合理的なサンプル値を設定しています
（UI上では該当項目に「？」ツールチップで補足）。この前提では、両サンプルとも事業成立最低単価が
提案単価・顧客現在単価を上回る結果になります（住宅: 約53円/kWh、事業所: 約40円/kWh）。これは計算の
誤りではなく、ファイナンス（自己資本比率・金利）やO&M等の仮定値次第で変わる結果であり、
感度分析ページでPPA料金・設備費の影響度が大きいことを確認しながら、前提条件を調整して
損益分岐点を探るのが本機能の使い方です。
